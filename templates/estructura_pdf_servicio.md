# Estructura PDF servicio técnico

## Encabezado

- Logo IBSolucion.
- Título: Servicio Técnico IBSolucion Móvil.
- Folio del servicio.
- Fecha.
- Cliente.
- Técnico responsable.

## 1. Datos del servicio

- Cliente.
- Obra / planta / ubicación.
- Contacto cliente.
- Teléfono.
- Email.
- Fecha.
- Hora inicio.
- Hora término.
- Tipo de servicio.

## 2. Equipo intervenido

- Tipo de equipo.
- Marca.
- Modelo.
- Número de serie.
- Ubicación del equipo.
- Condición inicial.

## 3. Diagnóstico

- Falla reportada por cliente.
- Diagnóstico técnico.
- Riesgos detectados.
- Fotografías iniciales.

## 4. Trabajo realizado

- Actividades realizadas.
- Repuestos utilizados.
- Lubricación aplicada.
- Ajustes realizados.
- Pruebas realizadas.
- Fotografías durante y después.

## 5. Estado final

- Estado final del equipo.
- Requiere nueva visita.
- Requiere repuestos.
- Requiere cotización adicional.
- Recomendaciones al cliente.
- Observaciones del técnico.

## 6. Recepción conforme

- Estado de recepción.
- Nombre receptor.
- Cargo.
- RUT.
- Comentarios del cliente.
- Firma cliente.
- Firma técnico.

## 7. Cierre

Texto sugerido:

El presente documento respalda el servicio técnico realizado en terreno. Las observaciones, recomendaciones, repuestos pendientes o trabajos adicionales indicados podrán requerir una cotización o visita posterior.
